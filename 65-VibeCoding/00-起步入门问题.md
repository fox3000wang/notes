# Vibe Coding

Vibe Coding（氛围编程）是2025年最受关注的科技热词之一，甚至被《柯林斯词典》评为年度词汇。简单来说，它是一种新兴的编程方式：开发者不再逐行手写代码，而是用自然语言向AI描述自己想要什么，让AI来完成具体的实现

## 如何hello world

要生成第一个项目，至少需要依赖以下两样东西

- Vibe Coding的开发工具
- 一个大模型

需要一个辅助你开发的AI

## 大模型

大模型相对好解决

使用Ollama

```bash
brew install ollama

ollama pull qwen2.5-coder:7b

# 设置上下文长度为 20000
OLLAMA_CONTEXT_LENGTH=20000 ollama serve

```

## 开发工具 Claude Code

```bash
# 参考
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

```bash

# 代理迁移到本地机场
export https_proxy=http://127.0.0.1:1087

curl -fsSL https://claude.ai/install.sh | bash

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

claude --version
```

```json
# 初始化配置

～/.claude/settings.json

# 本地跑大模型

{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:11434",
    "ANTHROPIC_AUTH_TOKEN": "ollama",
    "ANTHROPIC_API_KEY": "",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "80",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "syntaxHighlightingDisabled": false
}

ANTHROPIC_BASE_URL：指向 Ollama 的默认 API 地址。
ANTHROPIC_AUTH_TOKEN：Ollama 不需要认证，但客户端要求有值，填 ollama 即可。
CLAUDE_AUTOCOMPACT_PCT_OVERRIDE: 80：当会话上下文使用达到 80% 时，自动压缩历史，防止溢出。
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC: "1"：禁用非必要的网络流量，让你的数据更安全。

# 远程调用大模型
```

# Vibe Coding

Vibe Coding（氛围编程）是2025年最受关注的科技热词之一，甚至被《柯林斯词典》评为年度词汇。简单来说，它是一种新兴的编程方式：开发者不再逐行手写代码，而是用自然语言向AI描述自己想要什么，让AI来完成具体的实现

## 如何hello world

> 这个文档的目的就是让你在不额花费钱的情况下，把基本的环境搭建起来。

要生成第一个项目，至少需要依赖以下两样东西

- Vibe Coding的开发工具
- 一个大模型

## 部署大模型

> 部署大模型相对好解决, 但是也需要依赖工具，我们使用Ollama

```bash
#官网的安装模式可能在大陆安装不了 curl -fsSL https://ollama.com/install.sh | sh
brew install ollama           # macOS 特供
ollama pull qwen2.5-coder:7b

# 设置上下文长度为 20000
OLLAMA_CONTEXT_LENGTH=20000 ollama serve
```

## 开发工具 Claude Code

```bash
# 参考官方官网安装，就是会报错

# 先安装nvm github访问不稳定 也可以考虑用apt安装
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

export NVM_DIR="$([ -z "${XDG_CONFIG_HOME-}" ] && printf %s "${HOME}/.nvm" || printf %s "${XDG_CONFIG_HOME}/nvm")"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"



# 安装最新长期支持版 (目前通常是 v22 或 v23)
nvm install --lts

# 强制当前会话使用该版本
nvm use --lts

# 【关键一步】设置默认版本，这样每次登录自动生效
nvm alias default node

# 这里安装cc客户端
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

```bash

# 代理迁移到本地机场
export https_proxy=http://127.0.0.1:1087
curl -fsSL https://claude.ai/install.sh | bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
claude --version
```

```bash
# 初始化配置
nano ～/.claude/settings.json

# 本地跑大模型
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:11434",
    "ANTHROPIC_AUTH_TOKEN": "ollama",
    "ANTHROPIC_API_KEY": "",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "80",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "syntaxHighlightingDisabled": false
}
ANTHROPIC_BASE_URL：指向 Ollama 的默认 API 地址。
ANTHROPIC_AUTH_TOKEN：Ollama 不需要认证，但客户端要求有值，填 ollama 即可。
CLAUDE_AUTOCOMPACT_PCT_OVERRIDE: 80：当会话上下文使用达到 80% 时，自动压缩历史，防止溢出。
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC: "1"：禁用非必要的网络流量，让你的数据更安全。

# 远程调用大模型
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:11434",   // <- 这里
    // ANTHROPIC_BASE_URL=https://www.autodl.art/api/v1/anthropic
    "ANTHROPIC_AUTH_TOKEN": "ollama",                 // <- 这里
    // ANTHROPIC_AUTH_TOKEN=$API_TOKEN
    "ANTHROPIC_API_KEY": "",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "80",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "syntaxHighlightingDisabled": false
}
# 参考 https://www.autodl.art/docs/claude-opus-4-6-cc/
```

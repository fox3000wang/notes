# 远程云服务器算力环境搭建(无废话,一句话讲清楚版本)

## 0.基本的思路

- 先挑选一台服务器, 然后把相关的工具全部安装全，最后做成镜像,方便以后直接开箱即用。

## 1.初始化云服务器

- 选择一台配置符合模型最低需求,Ubuntu,PyTorch,Cuda,Python版本拉到最高。

## 2.安装基础的相关软件包和依赖

```bash

# apt 相关
sudo apt update && sudo apt install -y pciutils lshw zstd nano git nginx tree

# ollama
curl -fsSL https://ollama.com/install.sh | sh

# Claude Code客户端的依赖
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/HEAD/install.sh | bash
# 使用 gitee 镜像
#export NVM_SOURCE=https://gitee.com/mirrors/nvm.git
#bash -c "$(curl -fsSL https://gitee.com/mirrors/nvm/raw/master/install.sh)"
nvm install --lts && nvm use --lts && nvm alias default node

# Claude Code
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

# pnpm
npm install -g pnpm

# CodeX
npm install -g @openai/codex

# OpenClaw
curl -fsSL https://openclaw.ai/install.sh | bash

```

## 3.配置参考

```bash
# gpushare 恒源云专用, 把大模型目录迁移到 /hy-tmp 这个目录
echo 'export OLLAMA_MODELS="/hy-tmp"' >> ~/.bashrc
```

## 4.ollama抓取大模型

```bash

# 入门级别模型的地板模型
# 最低配置 v100 费用 0.5元/H
# 推荐配置 3090 费用 0.8元/H
# qwen3-coder:30b
# size:19GB 内存:32GB - 128GB 显存:18GB - 24GB
ollama pull qwen3-coder:30b

# 算力拉满适合基础满足正常使用
# 最低配置 6000D 费用 6元/H
# qwen3-coder-next:q8_0
# size:85GB 内存:85GB 显存:85GB
# NVIDIA 驱动CUDA 12.2+
ollama pull qwen3-coder-next:q8_0

```

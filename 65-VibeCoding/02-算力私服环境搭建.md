# 算力私服环境搭建

## 0.先启动一台云服务器,然后ssh登录

- 镜像选择非常关键：请选择包含 Python 和 CUDA 的深度学习基础镜像（如 PyTorch 镜像），这样能省去安装显卡驱动的麻烦。

```bash
# 1. SSH连接到你的GPUShare实例
ssh -p [端口] root@[实例IP]

# 先安装一些依赖
sudo apt-get update
sudo apt-get install -y pciutils lshw
sudo apt install -y nano
```

## 1.先安装ollama

```bash
# 可能还依赖
sudo apt-get install zstd

# 官网推荐安装模式
curl -fsSL https://ollama.com/install.sh | sh

```

## 2.ollama抓取大模型

```bash
# https://ollama.com/library/qwen3-coder
# 不到20G适合自己搭建私服
ollama pull qwen3-coder:30b

# 测试用, 比较小，速度快
ollama pull qwen3.5:0.8b
```

> > 如果不想远程访问，到这里就可以安装cc了。

## 3. 配置Ollama允许远程访问（如果你要用SSH隧道）

```bash
systemctl edit ollama.service

# 在打开的编辑器中粘贴：
[Service]
Environment="OLLAMA_HOST=0.0.0.0:11434"
```

## 4. 重启服务

```bash
systemctl daemon-reload
systemctl restart ollama
```

## 5.本地建立SSH隧道

```bash
#ssh -p [端口] -L 11434:127.0.0.1:11434 root@[实例IP] -N
ssh -L 11434:127.0.0.1:11434 root@207.148.97.30 -N

curl http://localhost:11434/api/tags
```
